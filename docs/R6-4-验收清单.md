# R6-4 验收清单（真机执行）

> 这一批**只能在你带显示的机器上做**：需要真实浏览器出图、真实字体排版。
> 离线/无显示环境里 PNG 与对比度都不可信——不要用它替代。
>
> 全部命令在 `plugins/dsh-image-video/` 下执行。

---

## 0. 前置（只做一次）

```bash
# 浏览器自动化（与采集脚本共用；不装进 devDependencies，避免锁文件膨胀）
npm i -D playwright
npx playwright install chromium

# 另开一个终端，起 harness 前端
cd <repo-root>
pnpm run dev:web          # 记下 URL，默认 http://localhost:5173
```

装完第一件事是确认 URL 真能打开工作台：

```bash
DSH_WEB_URL=http://localhost:5173 node scripts/check-contrast.mjs --theme light
```

能打印出「采样 N 个文本节点」就说明链路通了。打印「未检测到工作台根节点」说明右栏没渲染出来，先解决这个再往下走。

## 2. 改样式后做像素对比

```bash
# 2a. 新图采到独立目录（不要覆盖基线！）
DSH_BASELINE_OUT=docs/ui-baseline/current node scripts/capture-ui-baseline.mjs

# 2b. 比对（默认阈值 0.1%，单通道差 >20 才算"变了"）
node scripts/diff-ui-baseline.mjs

# 2c. 只看差异位置（输出标红图到 docs/ui-baseline/diff/）
node scripts/diff-ui-baseline.mjs --write-diff
```

退出码：有超阈值或缺失 → `1`。想临时放宽可以用 `--threshold 0.005`（0.5%），但**别写进脚本默认值**——那等于取消门禁。

判读：

- **差异集中在工具栏/面板边缘、幅度 1–2px** → 大概率是 R6-1 的间距收敛（见 §4 预期清单），接受并重采基线；
- **差异成片、某个区块整体位移** → 查 R6-2 的 `.iv-sub` 骨架是否漏改某个面板；
- **某张图整片变红** → 先看是不是采集时状态不同（比如 `mode-advanced` 需要先有素材/片段）。

## 3. 对比度（双主题）

```bash
node scripts/check-contrast.mjs --json .tmp/contrast.json
```

逐个主题跑、输出明细、按 WCAG AA 判定：正文 4.5:1，大字号（≥24px，或 ≥18.66px 且 bold）3:1。

**重点看这几类**（它们是小字 + 低对比的高危组合）：

| 位置 | 令牌 | 风险 |
|---|---|---|
| `.iv-meta` / `.iv-count` / 状态栏 | `--iv-tx3`（52% 混合） | 9–10.5px 配 52% 最容易踩线 |
| `.iv-meta--warn` | `--iv-warn` 实色 | R6-1 已确认用实色，核对是否还够 |
| `.iv-model-card-tips` / `.iv-tpl-desc` | `--iv-tx3` + 10px | 长段落最影响可读性 |

输出里会单列「底色是近似值（半透明叠层）」的节点——它们是渐变或图片背景上的文字，脚本算不准，**必须人工看**，不要直接判过。

修法优先级：① 换实色语义 token ② 字号上调一档（`micro`→`meta`）③ 这个字本来就不该用 `tx3`（比如它是主信息却配了三级色）。

## 5. 矩阵与走查

| 维度 | 取值 | 看什么 |
|---|---|---|
| 视口宽 | 380 / 420 / 768 / 1024 / 1440 | 工具栏不重叠、面板可滚、`.iv-dock` 单列切换正常 |
| 缩放 | 100% / 200% | 字不糊、按钮不变形、弹层不出屏 |
| 主题 | light / dark | 面色不透底、语义色不刺眼、监视器恒深 |
| 语言 | zh / en | 长英文不撑破按钮、ellipsis 生效（jsdom 测不了，必须这里看） |
| 键盘 | Tab 全流程 | 时间轴手柄可聚焦、弹层 Tab 不逃逸、Esc 关闭且焦点归还 |
| 读屏 | 任选一款 | 操作结果有播报（`.iv-notice` 不再重复念两遍） |

**必须走一遍具体交互**（只截静态图看不出来）：

1. 打开默认值弹层 → Tab 到底 → 焦点回到第一个，Esc 关闭 → 焦点回到「编辑默认值」按钮；
2. 打开帮助浮层 → Esc 关闭 → 焦点回到左栏问号；
3. 时间轴选中片段 → Tab 到手柄 → 方向键改起点、Shift+方向键跨秒、Home/End 到两端；
4. 三个面板各制造一次失败（断网/dev server 停）→ 确认**旧内容还在**、顶部有告警、点重试能恢复。

## 6. 回归门禁

```bash
pnpm run typecheck
pnpm exec tsdown && pnpm run check:bundle      # 入口 99% 已贴线，涨了先看是不是进了入口

pnpm run test:ui:changed                       # ① 先跑这个：R6 改动的针对性验证（32 条，秒级）
pnpm run test:ui                               # ② 再跑全量 46 个 UI 用例
bash scripts/gate.sh                           # ③ 全量五步
```

`test:ui:changed` 覆盖了 R6 全部改动：

| 文件 | 钉住什么 |
|---|---|
| `client-design-system` | 59 个令牌、无裸值、图标风格、pane 骨架 |
| `client-panel-state` | 四形态语义与重试回调 |
| `client-timeline-keyboard` | 手柄可聚焦 + 方向键真的改了片段 + Home/End 边界 |
| `timeline-nudge` / `overlay-position` | 纯函数边界（不需要浏览器） |
| `client-a11y` | 模式按钮、导出选择器、**弹层 focus 移入/回环/Esc/归还**、常驻播报区 |
| `client-models-catalog` / `client-ratio-slices` / `client-resource-folders` | 三个面板迁移后的行为 |

> **为什么先跑 `test:ui:changed`**：R6-3a/3b 的改动在离线环境只验证到「独立组件/面板级」，**渲染完整工作台的用例一次都没跑过**。这 32 条能在真机上几秒内告诉你"是不是本轮弄坏的"，比直接跑 46 个更快定位。
>
> 已排除的嫌疑（本沙箱实测）：内联 `gap: var(--iv-sp-*)`（回退 12 处后仍崩）、新增 CSS 块（移除后仍崩）、`PanelState` 的 JSX（改成 `return null` 后仍崩）。所以不是某一处写错，而是当前体积的工作台渲染整体超出这里的内存上限——**只能真机判定**。

## 7. 已知限制与豁免

| 项 | 现状 | 处理 |
|---|---|---|
| `pane-error.png` | 采集脚本没有对应场景（需要人为让某 pane 抛错） | 手动制造一次错误截图存档；或明确记录「本项豁免」 |
| 跨机器 diff | 字体 hinting 不同，几乎每张都超阈 | **只在同一环境内比**；换机器后重采基线并在 PR 写明原因 |
| 半透明叠层上的文字 | 脚本只能给近似底色 | 输出里单列，人工确认 |
| 图标/边框/焦点环对比 | 不在脚本范围（只看文本） | 走查时肉眼确认 |
| 长英文压力 | jsdom 无排版引擎，单测测不出 | 见 §5 语言行 |
