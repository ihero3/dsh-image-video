# 飞书需求文档（模力漫 AI 使用指引）↔ 本项目现状对照

> 来源：`https://cqbuerdt.feishu.cn/wiki/CKDfwyKy8ikr23kMLEjcI7xcnPc`（revision 10415）
> 对照时间：2026-10-21。文档是**对标产品（模力漫 AI）的产品使用指引**，共 11 章。
> 本项目定位是**桌面端插件**（本地优先，`R-BND-3` 明确不做云端/账号），因此"开户/团队/积分/审核/投放"整章属于**非目标**。

## 一、逐章对照

| 文档章节 | 本项目现状 | 结论 |
| --- | --- | --- |
| 一、开户流程（注册/认证/充值） | — | **非目标**（本地优先）|
| 二、团队管理（成员/部门/角色/分配积分/离职移交） | — | **非目标** |
| 三、积分使用（消耗/统计） | — | **非目标**（我们用 provider 直连计费）|
| **四、提示词提取库** | ❌ 无 | **缺口 G1**：图片→提示词提取 + 提示词库 |
| **五、AI 编剧（短剧生成 / 脚本裂变）** | 🟡 部分：`drama-series` 模板有 `creative-input`/`script` 节点，但**没有 LLM 生成** | **缺口 G5** |
| 六、AI 配音 | ❌（`voice-synthesize` 预留禁用 `R-BND-4`）| 暂不做 |
| 七、AI 投放素材 / 八、爆款裂变 | ❌ | 不做（营销侧）|
| 九、审核（内部/外部） | ❌ | 不做（本地单人）|
| **十·项目 / 片段** | 🟡 项目 ✓；**"片段"概念无**（我们项目下是素材+时间轴）| 见 G6 |
| **十·角色管理库 / 场景管理库 / 物品管理库** | 🟡 资源 `kind=role/scene/prop` ✓ 可挂参考图 ✓；但**三库没有分栏 UI、无"文件夹/集数"** | **缺口 G2** |
| **十·半自动·融合生图（角色+场景+物品+姿态+裁剪）** | 🟡 生成表单 + **单参考图** ✓；多物料合成/姿态/裁剪 ❌ | **缺口 G3** |
| 十·半自动·图生视频 | ✅ 首帧图生视频 ✓（缺"镜头类别/生成数量"）| 基本达成 |
| 十·半自动·文生视频 | ✅ | 达成 |
| **十·半自动·首尾帧视频** | 🟡 后端 `media[]` 已支持 `last_frame`；**UI 无入口** | **缺口 G4** |
| **十·半自动·参考生视频 / 视频续写** | 🟡 参考视频编辑 ✓（`media` 传 video）；续写 ❌ | 缺口（低优先）|
| **十·半自动·视频编辑（一句话指令）** | 🟡 后端支持视频编辑 ✓；**UI 无入口** | **缺口 G4** |
| 十·半自动·AI 换脸 | ❌（预留禁用）| 不做 |
| **十·全自动·创建生产线（剧本→分镜→物料→生图→视频→审核→导出）** | 🟡 `drama-series` 模板跑通"剧情→剧本→分镜→定妆图→镜头视频→字幕→合成"；**缺 AI 拆解分镜、批量改提示词、Excel 导入、审核** | **缺口 G6** |
| 十·全自动·导入生产线（Excel） | ❌ | 低优先 |
| 十一、模型介绍 | ✅ provider/model 可选 | 达成 |

## 二、由对照得出的新任务（并入 `docs/ROADMAP.md` P0）

| # | 任务 | 来源 | 价值 |
| --- | --- | --- | --- |
| **G1** | **提示词提取**（图片 → 提示词，落库到"提示词库"）| 四章 | 快速创作闭环的第一步，创作者高频 |
| **G2** | **物料库分栏**（角色/场景/物品 三库 + 参考图 + 批量导入 + 按库筛选）| 十章 | 你要的"角色归类"完整形态 |
| **G3** | **融合生图**（选角色+场景+物品 → 多参考图合成生成）| 十章 | 多物料一致性，是"专业工作流"的核心能力 |
| **G4** | **首尾帧 / 视频编辑 UI 入口**（后端已支持 `media[]`）| 十章 | 零后端成本，纯 UI 收益 |
| **G5** | **AI 拆解分镜**（剧本 → 分镜表，LLM 节点）| 五章 | 全自动生产线的前置 |
| **G6** | **生产线模板升级**（可编辑分镜 + 批量改提示词 + 导出）| 十章 | "专业工作流"的旗舰能力 |

> 备注：`AI 换脸 / 口型 / 配音` 仍按 `R-BND-4` 保持"预留 + 禁用"，不伪造成功。
