# dsh-image-video · 功能清单（当前实现）

> 更新：2026-11-09。这份是**"插件现在能做什么"的全量盘点 + 快速创作页的逐块细化**，不是建议稿。
> 事实来源（代码，不是文档）：`src/index.ts`、`src/host/rpc.ts`、`src/workbench/*`、
> `src/client/Workbench.tsx`（`paneCreate / paneCanvas / paneTimeline / paneResources / panePreview /
> paneAssets / paneExports / paneTasks / paneSkills / paneHealth / paneDiagnostics`）、`src/client/panels/*`、`src/config.ts`。
> 术语：**剧集** = 容器（内部字段仍是 `project`）；**设定/资源** = 角色/场景/道具等创作物料；**产物** = 生成出的图/视频。

# A. 插件全貌（所有功能域）

## A1. 三个模式（左栏切换）

| 模式 | 能做什么 |
|---|---|
| **快速创作**（`modeQuick`，默认） | 见 B 部分：两个标签页（内容生产 / 提示词·分镜）+ 内容生产页三个模块（① 剧本→成片、② 一句话出一镜、③ 剧本·分段） |
| **专业工作流**（`modeWorkflow`） | 节点画布：拖节点、连线、填参数、校验、运行/取消/重试；模板一键铺图；可存多份工作流并按剧集切换 |
| **时间轴 · 成片**（`modeTimeline`） | 三轨（视频/音频/字幕）剪辑、分割/复制/裁剪、字幕轨、导出渲染与进度、导出历史 |

## A2. 停靠区面板（右栏纵向排列，顺序即用户动线）

| 顺序 | 面板 | 功能 |
|---|---|---|
| 1 | **剧集资源**（`paneResources`） | 标题跟随剧集名（「<剧集名>资源」）；角色/场景/道具三类常驻，其余 4 类进「更多类型」；每行默认只显示 缩略图 + 名称（含参考图张数）+ `+`挂图 + 详情；使用记录/编辑/参考图/删除收进详情；「高级：分类与重绘计划」折叠；**默认收起**，点标题行右侧箭头展开 |
| 2 | **预览**（`panePreview`） | 固定 320px 舞台、媒体按 contain 收进框内；折叠后只留标题行（约 40px）；资源参考图、素材行、生成结果都往这里送 |
| 3 | **素材**（`paneAssets`） | 列表 + 类型筛选 + 搜索（文件名/提示词/模型）；顶部一行「本地产物：N 个 · X GB」+「在文件夹显示」；勾选批量删除/批量引用；单行登记/删除/预览；**默认展开**，标题行右侧箭头可收起 |
| 4 | **技能库**（`paneSkills`） | 与媒体素材同级的整体模块，排在媒体素材下面；导演 / 逆向两个独立库：导入（https / 本地目录 / `.json` / `.zip`）、手动新建、启用停用、删除（先备份）、在文件夹显示；内置默认技能只读可停用；**默认展开**，标题行右侧箭头可收起 |
| 5 | **导出历史**（`paneExports`） | 导出记录（文件名/比例/大小/时间）、失败原因、重试、按剧集筛选；顶部「导出成片」跳到时间轴；**默认收起** |
| 6 | **任务**（`paneTasks`） | 生成任务账本：状态/模型/耗时/字节；取消、失败原因展开、点行看产物、登记为素材、按原参数重跑、送参考位、加进时间轴；**默认收起** |
| 7 | 素材库体检（`paneHealth`，**默认隐藏**） | 体积排行 / 重复文件去重 / 剧集统计（运维用途） |
| 8 | 诊断（`paneDiagnostics`，**默认隐藏**） | outputs 文件数/字节/最老最新、队列、错误摘要 |

展示列（右侧 380px）标题为「三视创作」（头部 logo 下方的副标题是「三视创作工作台」，两个文案分属 `dockTitle` / `brandTagline`）：标题行整行都是收起按钮（`data-workbench-dock-collapse`），点标题或右端箭头都能收起。收起后整列让位给创作区，主区铺满面板整宽、不留空白列；右侧原位留一条 26px 的展开窄条（`data-workbench-dock-expand`），点它就能把展示列展开回来，不必回到顶栏按钮。顶部工具栏的展示列开关走同一个状态。窄档（<900）不显示窄条，仍由顶栏按钮开合浮层。

面板之外，头部还有一个**连接**入口（`data-workbench-connect-toggle`）：账号登录 / 自带 Key 双页签（`auth/*`），只显示余额与 Key 末四位，明文不下发；登录成功后自动开通/复用 Key 并写入凭证缝。

头部条带（`data-workbench-header`）与「当前生效参数」条（`data-workbench-defaults`）都当窗口标题条用：双击空白处进入原生全屏，再双击一次恢复原窗口尺寸；双击按钮、下拉、输入框等控件时保持控件自身行为。

> 隐藏靠 `maintenancePanes` prop（生产默认 false）；面板代码保留，运维排查时打开。

## A3. 媒体生成能力

| 能力 | 现状 |
|---|---|
| 生成类型 | 文生图 / 图生图（多参考图）/ 文生视频 / 图生视频 / 视频生视频（复刻）/ 视频编辑 / 续写 |
| 服务商 | `threevideo`（默认聚合器）/ `wanx`（百炼）/ `minimax`（官方，仅视频）/ `seedance`（火山方舟）；按模型家族自动路由 |
| 参考素材 | 多参考图（≤8，按序，首图=底图）；视频侧：尾帧图（`last_frame`）、参考视频（`reference_video`）、真人模式、续写（`continuation`）、复刻对比（`compare`） |
| 参数 | 图片尺寸（1:1/4:3/3:4/16:9/9:16）、视频比例（16:9/9:16/1:1/3:4/4:3）、视频时长 1–30s、风格（摄影/插画/3D/动漫/水墨）、模型 |
| 异步与找回 | 图片 `auto/async/sync` 传输；幂等键 + 未知状态策略（默认不重提）；视频任务轮询（默认 5s，整体 10 分钟超时）+ 取消 |
| 后处理 | 图片品牌水印（文字/位置/透明度/字号/留白/柔光可配） |
| 输出 | 落地 `outputs/`（宿主唯一解析点）；文件名带时间戳与提示词摘要 |

## B1. 模块折叠（①②③ 统一）

标题行**整行**是按钮（编号+标题+说明+右侧胶囊都可点），键盘可聚焦；① ② ③ 默认展开；
收起用 `hidden` **隐藏**整块（不卸载，提示词/分镜/勾选都还在），CSS 有 `.iv-module-body[hidden]{display:none}` 保证真的收起来。
旧「高级设置」模块已下线，入口都在模块内或壳层。

## B3.1 模块③ 剧本 · 分段

| # | 功能 | 现状 |

## B7. 双技能库（导演 / 逆向）

| 库 | 用途 | 选择位置 |
|---|---|---|
| 导演 `director` | 有提示词 → 按专业技能风格拆出分镜 | 本集工作区每段的「分镜技能」下拉 |
| 逆向 `reverse` | 一张图或一段短视频 → 提取可编辑的新提示词（"意向解析"） | 「提示词·分镜」页的逆向技能下拉 |

- 两个库独立存储（`skills/<kind>/<id>/skill.json` + `skills/index.json`），都像素材库一样公共可选、支持本地导入与内置默认。
- 内置技能只读：可停用、不可删除；用户技能删除前备份到 `skills/_backup/`。
- 导入安全：仅 `https://` 或本地绝对路径（目录 / `.json` / `.zip`）；zip 拒绝绝对路径、`..`、加密条目与未知压缩算法，解压总量上限 20 MB。
