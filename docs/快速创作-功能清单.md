## 1. 模块折叠（①②③ 统一）

| 功能 | 现状 |
|---|---|
| 折叠控件位置 | 三个模块**标题行最右**都有「收起 / 展开」胶囊 |
| 整行可点 | 标题行整体是一个 `<button>`：编号、标题、说明、右侧胶囊**都是点击区**；键盘 Tab 可聚焦、Enter/空格切换、聚焦有描边 |
| 默认状态 | ① 剧本 → 成片：**展开**；② 一句话出一镜：**展开**；③ 高级设置：**收起** |
| 收起的行为 | 用 `hidden` **隐藏**整块内容（不是卸载）：再展开时提示词、已改分镜、已勾资源都还在；CSS 有显式 `.iv-module-body[hidden]{display:none}` 保证真的收起来 |

## 2. 模块① 剧本 → 成片

| # | 功能 | 现状 |
|---|---|---|
| B1 | 剧本输入 | 6 行高文本域 |
| B2 | 生成模式 | 三选一：**图生视频** / **文生视频** / **视频生视频（复刻）**；选复刻时出现"参考视频"输入（可手填路径，也可用「媒体素材」里选中的视频一键填入）；缺参考片时给出提示、就地生成直接拒绝（零模型调用） |
| B3 | 分镜数 | 默认 4，范围 1–60 |
| B4 | 每镜秒数 | 默认 **6** 秒，1–30；逐镜可单独改 |
| B5 | 生成分镜 | 只拆镜 + 拼提示词，不生成、不花钱。生成后列出**可编辑分镜**：每镜可改画面提示词 / 视频提示词 / 本镜秒数；有改动才把 `shotDurations` 发回宿主 |
| B5.1 | 生成画布 | 编排 + 保存工作流 + 切到「专业工作流」画布，**不开始生成**（在画布上确认后再运行） |
| B6 | 就地生成 | 不跳画布，按分镜**串行逐镜**调用生成：图生视频先出图再出视频、文生视频直接出视频、复刻直接出视频；显示 `#n/total` 进度；失败时错误条带镜号，后续镜不再跑 |
| B7 | 手动挑选物料 | 默认自动匹配（按剧本里的名字）；也可手动勾选资源，**勾选顺序即可用顺序**，可 ↑/↓ 调整，顺序原样传给宿主 |
| B8 | 结果条 | 分镜数 / 工作流 id / 提醒（模型未选、分镜被截断等） |
| B9 | 缺料清单 | 点过「生成分镜 / 生成画布」后出现：剧本提到但剧集里没有的角色/场景/物品，每个名字后带「登记为角色 / 场景 / 物品」按钮，登记后自动按原入参重编 |
| B9b | 匹配到的物料 | 结果条里回显本次真正用到的资源（手动挑选 = 你选的那些；自动匹配 = 剧本命中的） |
| B10 | 手动分镜（折叠） | 粘剧本 → 拆成镜头表 → 逐镜编辑场景/角色/画面与视频提示词 → 单镜「送去生成 / 送画布」、整段「送一键成片」；默认收起 |

## 3. 模块② 一句话出一镜（单条生成）

| # | 功能 | 现状 |
|---|---|---|
| C1 | 提示词输入 | 多行文本域，`Cmd/Ctrl+Enter` 直接生图（**不再显示**那行快捷键提示） |
| C2 | 参考图 | 最多 **8 张**，按序排列（**第 1 张 = 底图**，其余 = 风格/脸部参考）；每张带**缩略图**，点缩略图或文件名 → 在「预览」面板打开该图；支持拖拽排序与 ↑/↓；可一键清空 |
| C3 | 视频专用（折叠） | 尾帧图 / 参考视频 / 真人模式 / 续写；默认收起，生图时不再占版面。尾帧图与参考视频**同样带缩略图、可点击预览** |
| C4 | 本次参数 | 图片尺寸 / 视频比例 / 视频时长（比例候选含 **16:9 / 9:16 / 1:1 / 3:4 / 4:3**）；默认「跟随默认」= 用上面 A4 的值，也可单独覆盖 |
| C5 | 模型选择 | 图片模型 / 视频模型两只下拉；默认跟随 A4 的服务商默认，可单独指定 |
| C6 | 模型详情（折叠） | 模型能力卡：可用模型、擅长、关键限制、实时校验徽章、刷新 |
| C7 | 用剧集设定拼画面（折叠） | 多选 角色 / 场景 / 道具 → 参考图预览 → 姿态 / 镜头 / 光线预设 → 拼成一段提示词 → 一次出图（原「融合生图」，从高级抽屉提到主路径） |
| C8 | 生成按钮 | **生成图片 / 生成视频 两个按钮，等宽等大**（避免点错）；生成中该按钮**就地变成「取消生成」** |
| C9 | 本次结果 | 生成后出现：图/视频预览 + 「去预览」+「设为参考图」+ 关闭 |
| C10 | 进度 | 已用时秒数 + 不确定进度条（服务商不给百分比） |
| C11 | 失败 | **只给错误提示条**（带服务商原文），不再有「换模型 / 缩短时长 / 清参考图」按钮组 |
| C12 | 已删除 | 三步引导、提示词风控预检、花费提示、"真实调用服务商"提示、失败补救按钮组 |

## 5. 数据与默认值口径

| 项 | 现状 |
|---|---|
| 容器 | 剧集（内部字段仍是 `project`，零迁移） |
| 运行时默认 7 字段 | `mediaMode / imageProvider / imageSize / imageStyle / videoProvider / videoAspectRatio / videoDuration`；其中 `mediaMode` 保留兼容但**不在界面展示** |
| 取值优先级 | 请求参数 > 工作台覆盖（override） > settings 持久默认 > **内置默认** |
| 内置默认 | `imageProvider=threevideo`、`imageSize=1024*1024`（显示 1:1）、`imageStyle=photo`（显示 摄影）、`videoProvider=threevideo`、`videoAspectRatio=9:16`、`videoDuration=10` |
| 来源徽章 | `override`→已覆盖、`settings`→来自设置、`none`→内置默认 |

## 6. 已知未做 / 待决策

| # | 项 | 说明 |
|---|---|---|
| 1 | 手动物料的最终顺序规则 | 现在是"勾选顺序 + 上下移"；你提过"可能想先用参考图生成视频、再用其他资源"，最终规则待定 |
| 2 | 就地生成不等成片 | 视频只用 `wait:false` 等"提交成功"（回显 taskId），不轮询到成片就进入下一镜；要"看到成片再继续"需加轮询 |
| 3 | 逐镜提示词覆盖不回写工作流 | 逐镜提示词只作用于「就地生成」与界面；落库工作流的提示词仍由宿主按剧本重算（要一致需宿主新增逐镜 prompts 入参） |
| 4 | `pipelines/run` 端点 | 宿主侧仍保留，客户端已不再调用（旧「一键生成（起跑）」按产品决定删除） |
| 5 | 工具侧取参链 | 生成工具仍读「覆盖层 + config」，不走内置默认层；所以"内置默认 10 秒"目前主要影响展示与工作台覆盖，**出片默认值是否也切到内置默认待确认** |
