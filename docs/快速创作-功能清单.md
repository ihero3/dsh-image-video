## 4. 我看到的 8 个问题（按影响排序）

1. **参数有两套**：顶栏 A4「当前生效参数」= 默认值；模块 ② C6 = 本次覆盖。两处都叫"尺寸/比例/时长"，用户不知道哪个生效。
   → 建议：顶栏只读（并标"默认"），② 里明确写「本次」；或干脆顶栏不显示这 7 项，只在"编辑"弹层里改。
2. **两个生成按钮**（生成图片 / 生成视频）占了主视觉一半，但它们共用同一段提示词和参考图。
   → 建议：一个「生成」主按钮 + 前面一个小切换「图片 | 视频」（视频才展开 C5 的四个视频专用开关）。
3. **三步引导 C1 长期占位**：剧集有产物后它就没用了。
   → 建议：只在"没有任何产物"时显示，有产物自动收起。
4. **① 与 ③D3 是同一件事的自动/手动两个版本**：都从剧本出发、都产出分镜。
   → 建议：合成一个模块，顶部切换「自动拆镜 / 手动分镜」。
5. **融合生图 D1 与 ② 的"参考图 + 提示词"重叠**：都是"多参考图 + 一段提示词"。
   → 建议：作为 ② 的一个入口按钮「用剧集设定拼画面」，点开才做资源多选。
6. **产出统计 D4 / 模型能力卡 D5** 在页面最底部，既不像"创作"也不给动作。
   → 建议：D4 删；D5 收进模型下拉。
7. **视频专用 4 个开关（尾帧/参考视频/真人/续写）常驻**：生图时全是无效控件。
   → 建议：按生成类型显隐。
8. **命名还有工程腔**：「仅编排（零花费）」「一键生成」「融合生图」「提示词工坊」「分镜计划」。
   → 建议统一成创作者语汇：先看分镜 / 开始生成 / 用设定拼画面 / 反推提示词 / 分镜表。

## 5. 建议的调整结果（供评审拍板）

```
① 出片（一块，自动/手动两模式）
   剧本输入 ─ 自动拆镜 / 手动分镜 ─ 缺料清单(可登记) ─ 先看分镜 / 开始生成

② 出单条（一块）
   用设定拼画面（资源多选，原融合生图） | 提示词 + 参考图 + 尾帧/参考视频
   类型切换 图片 | 视频　→　一个「生成」主按钮
   参数（本次覆盖）· 模型（带详情）· 结果 · 失败下一步

③ 高级（极简，默认收起）
   提示词工坊（反推提示词）· 模型能力卡
```

净效果：**3 块仍是 3 块，但每块只干一件事**；删掉产出统计、合并两处剧本逻辑、把融合生图提到主路径、视频开关按需出现。
