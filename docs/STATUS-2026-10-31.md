## 4. 新规划必须遵守的硬约束（每条都有证据）

1. **右栏可用宽度上限 575px**（`tabHostWidth` 实测）。任何"左物料 / 中创作 / 右产物"三栏布局物理放不下；
   纵向分段 + 低频折叠是当前同宽度下的正解（见 `QUICK-CREATE-FEATURES.md` §布局方案修正）。
2. **入口体积结构**：入口必须整包注册 i18n 字典（locale 服务禁止同一 NS 同一 locale 重复注册），
   **每新增 1 个文案 key 让入口长大 ~100 B**。预算：入口 raw 58,000 / gzip 19,400，
   总产物 raw 905,920 / gzip 194,780（`scripts/bundle-budget.mjs:42-50`，各 +20% 余量）。
   **实测（v1.0.1，清场后）**：入口 67,114 B = 预算 96%（清场前 69,412 B = 100%，删 25 个死 key 换来 4 个百分点）；
   总产物 1,013,991 B = 93%。重做页面若新增超过 ~50 个文案 key，先做「入口只注册 2 个 key + chunk 延迟字典」根治方案。
3. **单任务互斥**：只有一个 `generating` 状态，图和视频互相禁用。
4. **无宿主→客户端推送通道**：界面一致性靠轮询（当前统一轮询：有 running 2s / 空闲 5s，可见才轮）。
5. **文档一致性有测试钉死**：`tests/tasks-table.test.ts` 解析 `docs/TASKS.md` 的阶段表与任务行；
   新增任务行必须同步表，否则红。`tests/rpc-contract-drift.test.ts` 要求每个端点都写进 `API-SURFACE.md`。
6. **契约测试组**（改页面会碰到的）：`manifest-contract` / `client-bundle`（自包含单文件契约）/
   `i18n` 完整性 / `style-injection`（样式表里禁止反引号）/ `client-no-hardcoding`（产物里不得出现绝对路径与模型名）。
7. **数据 schemaVersion 4**，读入自动迁移、只升不降、迁移前备份（`MIGRATION-SCHEMA-V4.md`）。
8. **ffmpeg 不打包 sidecar**：安装检测 + `DSH_FFMPEG_PATH` 覆盖（`REQUIREMENTS.md` §14-D3）。
9. **异步图片端点不可用**（上游 404），走同步降级、无幂等键（`REQUIREMENTS.md` §16-17）。
10. **TTS 未接**：`voice/synthesize` 已就绪但 provider 缺；接口通了只需注入 provider，界面零改动。
11. **`lib/` 不入库**，由 `pnpm run build` 生成；宿主私有插件复制只认 `lib`。
12. **门禁 5 道**：`bash scripts/gate.sh`（typecheck / build / 全量测试 / 体积预算 / 覆盖率阈值）。
