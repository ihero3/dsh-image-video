# 3 分钟演示脚本（v1.0.0）

> 目的：3 分钟里让人相信「这套工作台能从头做到一条能发的片子」。
> 前置：示例包 [`examples/hello-workbench/`](../examples/hello-workbench/README.md) 已存在；
> 宿主已重启到带 A-6 平台词的版本。

## 分镜表

| 时间 | 画面 | 操作 | 你要说的话（要点） |
| --- | --- | --- | --- |
| 0:00–0:15 | 桌面宿主，右侧栏 | 点右侧栏图标打开 **图片/视频工作台** | 「这是对话之外的创作面：项目、素材、画布、时间轴、导出，全在一个侧栏里。」 |
| 0:15–0:30 | 工作台顶栏 | 指一下版本徽章 / 状态行 | 「1.0.0。产物这版瘦了一半以上——画布依赖交给宿主了，插件只管业务。」 |
| 0:30–1:00 | 项目区 → 导入 | **导入项目包** → 选 `examples/hello-workbench` | 「拿到别人的项目，包里有素材/工作流/时间轴，导入即完整可用；包内带 sha256，缺件会明说。」 |
| 1:00–1:30 | 画布 | 打开示例工作流，框选/拖动，指节点连线 | 「三节点一条链：提示词 → 首帧 → 视频。节点可单跑，也可整链跑；运行记录在侧栏。」 |
| 1:30–2:05 | 快速创作 | 输入一句提示词 → **生成图片**（1 次真实生成，产生费用） | 「不必回对话：这里直接调同一对工具，产物自动登记成项目素材、写进任务账本。」 |
| 2:05–2:30 | 时间轴 | 拖素材上视频轨，加一条字幕，开「烧字幕」 | 「时间轴是常规 NLE 手感：轨道、片段、字幕、转场；预览不用等导出。」 |
| 2:30–2:50 | 导出 | 点导出 → 展示进度与产物四件套（成片/封面/字幕/清单） | 「导出会生成成片、封面帧、字幕文件和清单，失败会给人话诊断而不是一串 ffmpeg 日志。」 |
| 2:50–3:00 | 收尾 | 回项目区，指「导出项目包」 | 「整个项目可以打包带走，换台机器继续剪。」 |

## 录制注意

- **金钱边界**：分镜里只有 1:30–2:05 那一步是真实生成（图片）。想零花费录制就提前生成好，
  这一段改成「播放已有结果 + 说明」。视频生成（`media/generate` + `video`）另算一次费用，
  演示里用已有成片，不要现场跑。
- 分辨率 ≥1440×900；侧栏宽度拉宽到能同时看到画布和检查器。
- 录制前把诊断面板（工作台内）收起来，演示结束再打开说一句「排障有面板」。
- 别在画面里露出 API Key、绝对路径、服务商后台；工作台产物按约定不含这些，但输入框要清空。
- 版本口径以 `GET /image-video/status` 为准；如果界面头部和它不一致，说明有旧客户端实例，
  先刷新/重启再录。

## 台词备选（更短，30 秒版）

> 「一个侧栏，从提示词到成片：项目包能导入导出，画布能单跑节点，时间轴能直接剪，
> 导出带封面和字幕。1.0 的产物比上一版小了一半——因为画布依赖不再塞进插件里了。」
