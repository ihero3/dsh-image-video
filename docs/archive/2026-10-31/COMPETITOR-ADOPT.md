# 对标模力漫AI「使用指引」：该结合什么、不结合什么

> 对标对象：模力漫AI（`molimanai.com`，不贰科技集团）《使用指引》
> 对标时间：2026-10-23｜我方基线：`dsh-image-video v1.0.0-workbench-78`
> 结论口径：**不做 1:1 抄功能**。只把与「生图 / 生视频 / 成片」强相关、且能落到现有骨架上的拿进来。

## 0. 先认清定位差异（这决定了 70% 的条目是否要抄）

| | 模力漫AI | 我们 |
| --- | --- | --- |
| 形态 | 云端 SaaS，多端（网页/企业团队） | 本地桌面插件（Harness 右栏），单机单用户 |
| 商业模型 | 开户 → 认证 → 积分充值 → 团队分配积分 | 无自营计费；走用户自己的服务商 Key（Threevideo / 万相 / MiniMax / Seedance） |
| 核心闭环 | 创意构思 → 内容生成 → 成片 → **多端预审分发/投放** | 提示词/素材 → 画布生产链 → 时间轴成片 → **工程化交付（项目包/导出四件套）** |
| 强项 | 组织结构、审核流、投放素材、平台公共素材库、自研模型矩阵 | 多服务商可选、节点级可编程生产链、本地素材与工程文件、零云依赖 |

**所以真正该对标的只有：四（提示词提取库）、五（AI编剧）、六（AI配音）、九（审核里的"体检"部分）、十（AI动画生产）。**
一/二/三（开户/团队/积分）和七/八（投放/爆款裂变）是 SaaS 商业侧能力，本地插件抄了没有意义。

## 2. 建议结合进来的（按优先级，全部能落到现有骨架）

### P0-1 语音链：剧本 → 台词 → 配音 → 时间轴音轨（对应竞品 六）
- **为什么必须**：短剧/动态漫的成片没有配音就只是"动图"；这一条打通后，我们的成片才叫成片。
- **落点（已存在）**：`voice-synthesize` 节点（现在 planned）、资源类型 `voice`、时间轴 `audio` 轨、导出 burn 字幕。
- **要补**：TTS 适配器（一个服务商即可起步）+ 音色列表端点 + 配音任务进任务账本 + 客户端"配音"面板（文本→音色/语速/音调→生成→试听→放上时间轴）。
- **验收**：一段 3 句台词，一次生成，自动落到 `audio` 轨，导出成片有声音。

### P0-2 生产线向导化：把「五步」做成一条可视路径（对应竞品 10.6）—— **已落地第一版（2026-10-23）**
- **为什么值得**：我们已经能跑整链，但用户（尤其新用户）不知道"先干什么"；竞品靠向导把留存拉起来。
- **落点**：`production-line` 模板 + `storyboard/plan` + `workflows/run`。
- **要补**：向导式 5 步（剧本 → 分镜 → 物料 → 生图 → 视频），物料支持**自动匹配 / 手动选择 / 严格模式**，分镜表支持批量改提示词（对应 B-15 分镜表 UI）。
- **验收**：粘贴一段剧本 → 5 步走完 → 出 4 个分镜视频，无手工建节点。
- **已交付**：`pipelines/compose|run` + 快速创作面板的「一键成片」卡片（先零花费编排预览，再一键起跑；
  成功后自动切画布看运行记录）。待补：物料挑选/自动匹配 UI、分镜表逐行改词（B-15）、Excel 导入。

### P1-1 资源库闭环：分类 + 参考图→提示词→重绘（对应竞品 10.3）
- **要补**：资源分组（文件夹/标签）、从参考图一键 `prompts/extract` → 应用为生成参数 → 二次生成；同名冲突提示。
- **为什么**：角色一致性是我们相对竞品的薄弱点，而它是动态漫的第一痛点。

### P1-2 融合生图参数化：姿态 / 镜头类别 / 场景裁剪（对应竞品 10.4）
- **要补**：姿态预设（站/坐/打斗/特写）、镜头类别（全景/中景/近景/俯拍）、场景图裁剪框选。
- 这三项是"能出可用镜头"和"出来像贴纸"的分水岭。

### P1-3 模型能力卡 + 提示词规范校验（对应竞品 十、十一）
- **要补**：每个模型一张卡（擅长/时长上限/分辨率/是否支持首尾帧/参考视频/成本档位）；提交前校验提示词（背景干净、单人、涉政涉黄等风险词）。
- 不抄竞品的营销式模型介绍，只做**选型决策**需要的最小信息。

### P2 视频续写显式化 / 对口型 / 多比例切片
- 续写：把"参考视频 + 尾帧 + 续写时长"做成一个模式（现在能手工凑）。
- 对口型：等 P0-1 的 TTS 就绪后做，依赖供应商能力。
- 多比例切片：竞品"投放素材"里唯一与我们相关的一点——成片后一键出 9:16 / 1:1 切片。

## 3. 明确不结合的（以及原因）

| 竞品能力 | 不做的原因 |
| --- | --- |
| 开户 / 注册登录 / 企业认证 | 我们无云端账号体系；宿主已有身份与服务商 Key |
| 积分充值与消耗、分配积分 | 无自营计费；成本信息由服务商账单与任务账本承担 |
| 团队/部门/角色/离职移交 | 单机单用户形态；要多人协作应走"项目包 + git"，不做组织架构 |
| 内部/外部审核流 | 单人本地没有"审给谁"；保留**导出前体检 + 数据巡检**这一层就够 |
| AI 投放素材（剧集解析/高光解说/高光混剪） | 需要剧集长视频解析与投放领域知识，和"生图生视频"弱相关 |
| 爆款素材裂变 / 广告主管理 | 投放平台侧业务，不属于创作工具 |
| 平台公共素材库（公众角色/场景上传） | 无云端素材市场；我们是本地库 + 项目包交换 |
| Excel 导入生产线 | 后置；先做"粘贴文本 → 拆分"，Excel 等真有批量需求再加 |
| 自研模型矩阵介绍 | 我们不做模型，只做路由；用 P1-3 的能力卡替代 |

## 4. 一句话结论

竞品把「组织 + 审核 + 投放」做成了 SaaS 护城河，我们不该跟；但它在**创作主链的完整度**（配音、生产线向导、资源库闭环）上确实领先。
我们该补的只有 **P0 两项（语音链 / 生产线向导）**，补完这两项，创作主链的覆盖就从"缺一条声轨 + 缺一层引导"变成闭环，其余按 P1/P2 增量排。
