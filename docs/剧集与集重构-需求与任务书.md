## 二、背景、目标与非目标

**背景**：现有数据只有剧集（project）一层，剧本、分镜、生成结果都挂在剧集上；用户做多集短剧时只能复制剧集或反复手改，素材也无法跨集复用。快速创作页同时存在"一键成片 / 单条生成 / 高级设置（融合生图、提示词工坊、分镜）"多套入口，职责重叠。

**目标**：一集是创作与交付的最小单位；剧集只做归类与公共资源；技能与素材可跨集复用。

**非目标**：不做账号 / 云同步；不改供应商协议；不做多轨时间轴重写；不删除任何已有成片文件（只删记录）。

## 三、需求清单

| ID | 需求 | 入口 / 行为 | 验收 |
|---|---|---|---|
| R-EP-01 | 四层实体 | 剧集 → 集 → 分段 → 分镜；集按 `no` 排序；删集后该剧集至少保留第 1 集（宿主懒建） | 新建剧集自动出现"第1集"；删掉最后一集后刷新仍有第1集 |
| R-EP-02 | 集的剧本与备注 | 本集工作区顶部剧本区，失焦自动保存，状态显示"未保存 / 已保存" | 输入后失焦，重进该集内容仍在 |
| R-EP-03 | 分段 | 每段一条带时长（5/10/20/30 秒快捷）的提示词；可插入、重排、删除；总时长实时显示 | 插入到第 2 位后序号连续为 1..n；总时长等于各段之和 |
| R-EP-04 | 引用（资源 / 素材） | 集内引用只存 id；分段与镜头各自另有引用；正文用 `[@n]` 顺序号 | 断链引用显示失效占位而不是报错；上移后 `[@n]` 顺序跟着变 |
| R-EP-05 | 全局素材库 | 素材库不按剧集过滤，所有剧集共用；集内可直接引用 | 在 A 剧集登记的素材，B 剧集的镜头选择器里也能选到 |
| R-EP-06 | 拆镜 | 分段提示词 + 导演技能 + 模型 → 分镜镜头（画面提示词 / 视频提示词 / 时长） | 拆镜后镜头落库；重开该集仍在 |
| R-EP-07 | 逐镜编辑与就地生成 | 每镜可改画面/视频提示词、时长、模型；单镜出图 / 出视频 | 生成请求带上 `episodeId`/`segmentId`/`shotId`，任务列表可按集追溯 |
| R-EP-08 | 按镜选资源 | 每镜一个选择器，候选 = 本集引用 + 全局素材，按 `kind:id` 去重 | 已选的不会重复出现在同一镜的候选里 |
| R-EP-09 | 分镜同步工作流 | 一键把本集所有镜头映射成工作流：每镜 图 → 视频，末尾预览 | 重复点两次仍只有一份工作流（id 固定 `wfl-ep-<集id>`） |
| R-EP-10 | 单集导出 | 导出 `episode.json` + 本集引用到的素材文件 | 缺文件写进 `missing[]`，不中断导出 |
| R-EP-11 | 导演技能库 | 有提示词时选技能，按专业技能风格拆镜 | 每段的技能下拉只列启用项；已停用的历史值仍能回显 |
| R-EP-12 | 逆向技能库 | 选图 / 短视频 → 提取可编辑的新提示词（"意向解析"） | 提取结果进入草稿框，可改名后存进本集提示词库 |
| R-EP-13 | 技能公共可选 | 两个库都像素材库一样全局可用；支持本地导入、内置默认、启停、删除、打开目录 | 内置技能不可删只可停用；删除前有备份 |
| R-EP-14 | 提示词按集归属 | 提示词记录带 `projectId` / `episodeId`；「提示词·分镜」页只列本集 | 切集后列表跟着变，不会串集 |
| R-EP-15 | 主区两 Tab | 「内容生产」/「提示词·分镜」；"带入生成"自动切回内容生产 | 在提示词页点带入，生成表单可见且已填好 |
| R-EP-16 | 下线旧入口 | 旧"高级设置"模块与其提示词工坊入口移除 | 页面不存在 `data-module="advanced"`，工坊只在新 Tab 里 |
| R-EP-17 | 默认剧集 / 集 | 没有剧集时自动建默认剧集；没有集时宿主懒建第 1 集 | 首次打开即可直接用，不出现"先建剧集"阻断 |
| R-EP-18 | 就地生成等成片 | 视频 `wait:false` 提交后必须等任务落成片，再进下一镜 | 任务失败时停在该镜并报镜号；不是"提交成功就继续" |

## 四、已确认的产品决策

| 编号 | 决策 | 理由 / 影响 |
|---|---|---|
| C1 | 素材库全局；剧集资源是剧集级；每集的图/视频可从"剧集资源 + 全局素材"选 | 跨集复用素材，但不把别的剧集的私有资源混进来 |
| C2 | 引用分类新增 `costume`、`ungrouped`；`brand` 只做读取兼容、不在新 UI 暴露 | 老数据不丢，新界面不出现无人维护的分类 |
| C3 | 数据层允许 分段:分镜 = 1:N；UI 默认 1:1 | 一次拆镜只生成一份分镜，但保留以后"一段多版分镜"的空间 |
| C4 | 按镜选择图片/视频资源，放在镜头行内 | 用户按镜头工作，不需要回到集级去配 |
| C5 | 就地生成的视频必须等成片 | 否则串行推进会在"第几镜"上失真 |
| C6 | 删集只删元数据引用，保留 outputs 文件 | 成片是用户的资产，记录可以重建，文件丢了不可恢复 |

## 五、数据模型

| 实体 | 关键字段 | 说明 |
|---|---|---|
| `EpisodeRecord` | `projectId`、`no`、`title`、`remark?`、`script{text,updatedAt}`、`segments[]`、`storyboards[]`、`resourceRefs[]`、`assetRefs[]` | 集是剧本与分镜的容器 |
| `SegmentRecord` | `order`、`durationSec`、`promptText`、`imageModel?`、`videoModel?`、`skillId?`、`refs[]`、`storyboardId?` | 时长快捷 5/10/20/30 |
| `StoryboardRecord` | `episodeId`、`segmentId`、`skillId?`、`shots[]`、`updatedAt` | 一个分段可以有多份（数据层） |
| `ShotRecord` | `order`、`durationSec`、`imagePrompt`、`videoPrompt`、`imageModel?`、`videoModel?`、`refs[]` | 就地生成的单位 |
| `SegmentRef` | `kind: 'resource' \| 'asset'`、`id`、`order` | `order` 与正文 `[@n]` 一一对应 |
| `SkillRecord` | `kind: 'director' \| 'reverse'`、`name`、`description?`、`prompt`、`builtin`、`enabled`、`source?` | 存储 `skills/<kind>/<id>/skill.json` |
| `PromptRecord` | `name`、`text`、`tags?`、`projectId?`、`episodeId?` | 「提示词·分镜」页按集过滤 |

**不变式**：引用只存 id，正文用 `[@n]`；断链必须可显示、可删，不阻断整页；技能与素材的体积/长度上限在宿主校验，客户端只做提示。

## 六、宿主端点（本次新增/变更）

| 组 | 端点 | 说明 |
|---|---|---|
| 集 | `episodes/list`、`create`、`get`、`update`、`remove`、`reorder` | `remove` 支持 `force`；只删记录 |
| 集级引用 | `episodes/resources`、`episodes/assets` | 动作 `list / add / remove / move` |
| 分段 | `segments/list`、`create`、`update`、`remove`、`reorder` | 顺序连续 |
| 分镜 | `storyboards/list`、`get`、`save`、`remove` | `save` 不带 `id` 即新建 |
| 技能 | `skills/list`、`get`、`save`、`import`、`toggle`、`remove`、`reveal` | 导入接受 `https://`、本地目录、`.json`、`.zip` |
| 导出 / 同步 | `episodes/export`、`workflows/sync-episode` | 导出到 `outputs/episodes/<集id>/`；同步为幂等工作流 |
| 提示词 | `prompts/list`、`save`、`extract` | 支持 `projectId` / `episodeId`；`extract` 支持 `skillId` |

完整字段与错误语义见 `docs/API-SURFACE.md`。

**关键实现口径**

- 工作流 id 固定为 `wfl-ep-<集id>`，节点 id 由镜头 id 推导（`img-<shotId>` / `vid-<shotId>` / `prv-episode`），所以重复同步是覆盖而不是新增。
- 技能导入先校验全部 zip 条目名，再解压；拒绝绝对路径、`..`、`.`、反斜杠、控制字符、加密条目与未知压缩算法；单条与总量上限 20 MB。
- C5 的就地生成：`wait:false` 后每 1 秒查一次任务账本，最长 15 分钟；失败/取消/超时都带镜号停下。

## 八、明确不做 / 待你拍板

| # | 项 | 当前默认做法 | 需要你确认的点 |
|---|---|---|---|
| 1 | 分段:分镜 1:N 是否上 UI | 数据层支持，UI 只给一份 | 是否要"一段多版分镜（A/B 版）"入口 |
| 2 | 就地生成的轮询参数 | 1 秒 / 15 分钟写死在客户端 | 是否按模型可配，或改成配置项 |
| 3 | 内置技能的提示词内容 | 我写的 4 条示例（电影感导演、动漫导演、单图逆向、短剧逆向） | 文案是否符合你的专业口径，需要你或设计过一遍 |
| 4 | 删集是否要二次确认 | 未加确认弹窗 | 是否需要"输入集名确认"级别的保护 |
| 5 | 导出目录 | 固定在 `outputs/episodes/<集id>/` | 是否允许用户选目录 |
| 6 | 旧入口下线的范围 | 只下线了空壳的"高级设置"模块 | 快速创作页的两个模块是否也要继续合并 |
