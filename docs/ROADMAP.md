## 二、新路线图

### P0 · 让「快速创作 + 专业工作流」先好用（发布前必须）

> 新增 6 项来自飞书对标文档（`docs/WIKI-GAP.md` G1–G6），与下面 F1–F7 合并排期；
> 建议顺序：**F1 → F2 → G3（融合生图）→ G2（物料库）→ G1（提示词提取）→ F3 → F4 → G4 → G5/G6**。

1. **F1 参数就地可改**：尺寸/风格/时长/比例在面板里改，改完即用于下一次生成（不必去 composer）。
2. **F2 多参考图选择器**：选多张素材 → `images[]`（后端已支持），按顺序=底图/风格参考。
3. **F3 生成进度**：`tasks/running` 的 `startedAt` → 已用时 + 进度条（图片无百分比时显示"生成中 · 12s"）。
4. **F4 模板补齐到 4 个**：`quick-image`（单图）、`quick-video`（单视频）、`storyboard`（图文分镜）、`cover`（封面图），让画布 2 次点击出片。
5. **F5 素材列表批量操作**：多选 → 批量删除 / 批量引用到提示词 / 批量挂到某资源。
6. **F6 资源资料库**：资源可挂多张参考图（1→N）、按资源看关联素材、"把选中素材归到这个角色"。
7. **F7 已知缺口收口**：B16 体积（A 侧外置 React Flow/d3，需配合宿主模块表）、B17 片段手柄接线。

### P1 · 发布（v1.0.0）
- 版本号跨到 `1.0.0` + 发布说明 + 3 分钟演示（含一个示例项目包）+ 迁移说明（schema v4）。
- 验收：五道门全绿、732+ 测试、真实生成一次图片与一次视频（owner 授权后）。

### P2 · 时间轴精剪（边运营边做）
1. **T1** 片段手柄/裁剪交互打磨（B17）+ 音频波形。
2. **T2** 字幕样式（字体/字号/描边/位置）＋ 逐句微调。
3. **T3** 关键帧动画（缩放/位移/透明度）。
4. **T4** 多时间轴批量导出 + 导出历史按项目归档 + 暂停/恢复。
5. **T5** 时间轴整体播放预览（实时合成）。

### 明确不做（保持焦点）
云端协作/账号体系 · 团队资源池 · 自动混剪/高光解说 · 口型/换脸（维持 `availability` 预留 + 禁用）。
