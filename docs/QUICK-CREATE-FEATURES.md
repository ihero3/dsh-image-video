# 「快速创作」功能清单与布局优化建议

> 盘点时间：2026-10-28 · 代码事实源：`src/client/Workbench.tsx`（4332 行）、`src/client/PipelineCard.tsx`、
> `src/client/VoiceCard.tsx`、`src/client/api.ts`、`src/client/locales.ts`
> 目的：一次性看清「现在有什么 / 缺什么 / 怎么摆」，供 owner 决策布局与优化顺序。

---

## 0. 现状结构（一句话）

快速创作 = **一个超长单列**（提示词 → 参考 → 视频槽 → 参数 → 生成 → 进度 → 融合 → 工坊 → 分镜）
\+ **一键成片卡**（置顶）\+ **底部停靠区**（预览/素材/任务/导出/资源/健康/诊断，`.iv-dock` 自适应栅格）。
模式切换只有三个：**快速创作 / 专业工作流 / 时间轴**。

```
┌ 顶栏：项目选择 · 模式 tab · 默认参数弹层 · 帮助 ─────────────────────────────┐
│ 左：42px 图标栏                                                              │
├ 主区（单列，从上到下）──────────────────────────────────────────────────────┤
│ ① PipelineCard   一键成片（剧本→分镜→编排→运行）                              │
│ ② Hero           步骤条(对话→产物→归档) + 提示词 + 参考图 + 视频槽 + 参数 + 生成 │
│ ③ Fusion         融合生图（角色/场景/物品 → 组合提示词 → 生成）                 │
│ ④ PromptStudio   提示词工坊（从图提取 → 草稿 → 入库 → 应用）                    │
│ ⑤ Storyboard     剧本分镜（脚本 → 分镜表 → 去生成 / 去画布）                    │
├ 停靠区 .iv-dock（auto-fit minmax(232px,1fr)；窄容器降为单列 max-height:44vh）──┤
│ 预览 · 素材 · 任务 · 导出 · 资源 · 健康 · 诊断                                 │
└──────────────────────────────────────────────────────────────────────────────┘
```

**关键事实**：快速创作**不选模型**（`runGenerate` 不传 `model`/`provider`，全走宿主默认值），
默认值只能在顶栏弹层里改；生成参数（尺寸/比例/时长）是**裸 `<input>`**，不是下拉。

## 3. 布局问题诊断（优化靶点）

1. **单列过长**：Hero 一张卡里塞了 6 个功能区（提示词/参考/视频槽/参数/按钮/进度），手机/窄窗下滑到参数就看不到提示词。
2. **参数不可发现**：尺寸/比例/时长是裸 input，用户不知道可填什么；模型完全不可选，"生成结果不符合预期"时无处调整。
3. **结果与动作分离**：生成完结果在底部停靠区，按钮在中部；一次创作要上下滚动 3~4 次。
4. **五块功能各自吃资源**（Hero 参考图 / 融合 / 分镜 / 工坊 / 一键成片），但资源选择器分散在 5 处，**没有统一的"物料区"**。
5. **停靠区 7 个面板平铺**（auto-fit minmax 232px）：宽屏还行，窄屏单列 + 44vh 滚动，优先级不分（诊断/健康这种低频面板和素材抢位置）。
6. **无"下一步"引导**：失败/缺失物料/风控命中，都只给文字，不给一键修复。

## 4. 三套布局方案

### 方案 A（推荐）三段式：左物料 / 中创作 / 右产物

```
┌ 顶栏：项目 · 模式tab · 模型选择器(带能力卡) · 帮助 ┐
├ 左 260px ──────┬ 中 1fr（创作流）──────────┬ 右 320px ────────┤
│ 物料区          │ 步骤 1 提示词（+风控提示）  │ 产物（本次结果大图/视频）│
│ · 素材（筛选/搜索）│ 步骤 2 参考（chips + 融合/分镜入口）│ 任务队列（进行中/历史）│
│ · 资源库（分类）  │ 步骤 3 参数（尺寸/比例/时长/续写）│ 导出（成片/多比例）│
│ · 提示词库       │ 步骤 4 生成（按钮 + 进度 + 下一步建议）│ 诊断（折叠）    │
└────────────────┴──────────────────────────┴─────────────────┘
```
- 动线：**左边选料 → 中间写+调+生成 → 右边立刻看结果**，一屏完成，不用来回滚。
- 融合生图/分镜/一键成片 → 作为中间区的「高级模式」抽屉（不常驻，避免抢空间）。
- 窄屏（<1180px）：右栏折叠为底部抽屉，左栏折叠为图标条。

### 方案 B 卡片流（改动最小）
保持单列，但把 Hero 拆成 4 张可折叠卡：提示词卡 / 参考卡 / 参数卡 / 生成卡；
生成卡内联展示进度与**本次结果缩略图 + "查看/设为参考"**。
- 优点：几乎不重构布局，一天能出；缺点：仍是纵向滚动，宽屏浪费空间。

### 方案 C 双栏 + 抽屉（折中）
主栏创作流，右栏固定 dock（产物/任务），其余面板（资源/导出/诊断/健康）进抽屉；
融合/分镜/工坊 → 提示词框旁的三个"魔法按钮"打开抽屉。
- 优点：比 A 轻；缺点：抽屉模式上下文切换成本略高。

## 5. 优化优先级建议

| 优先级 | 事项 | 理由 |
|---|---|---|
| **P0** | 布局改 A（或 B 过渡）＋ 参数模型化（下拉+常用值+模型选择器带能力卡） | 直接影响"能不能用对"，决定观感 |
| **P0** | 结果就地展示 + 生成完自动定位 + 失败给"下一步"按钮 | 去掉来回滚动，减少放弃率 |
| **P1** | B 批次 8 项接线（续写/融合参数/多比例/风控/分类/重绘/物料挑选） | 宿主与 API 都好了，纯 UI 工作，性价比最高 |
| **P1** | 统一"物料区"（素材+资源+提示词库三合一，带搜索） | 消除 5 处分散选择器 |
| **P2** | 分镜 ↔ 一键成片互通（分镜直接编排） | 打通"剧本→成片"链路 |
| **P2** | 任务面板增强（重试/失败展开/跳产物）＋ 预览面板加"用作参考/首帧" | 打磨 |
| **P3** | 配音合成（等 TTS）· 多任务并发 | 依赖外部/架构 |

---

## 6. 一句话结论

**能力不缺，缺的是"摆法"**：现在是把 12 个能力竖着叠在一列里；
改成「左物料 / 中创作 / 右产物」的三段式，配合参数下拉 + 模型能力卡 + 结果就地展示，
再把这轮已就绪的 8 个 B 批次能力接进去，快速创作就能从"能用"变成"顺手"。
