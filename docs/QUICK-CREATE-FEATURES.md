### ⚠️ 布局方案修正（重要）

原推荐方案 A「左物料 260 / 中创作 1fr / 右产物 320」**实测不可行**：
DSH 右栏 `tabHostWidth` 最大只有 **575px**，三栏（260+内容+320）物理放不下。

**T8 采用同宽度下的正解：纵向分段 + 低频折叠**——
融合生图 / 提示词工坊 / 剧本分镜 / 模型能力卡收进「展开高级」抽屉（默认收起），
主视线内保持闭环：`提示词 → 参数 → 模型 → 生成 → 本次结果`。
若将来右栏支持更宽，再按方案 A 拆三栏（`data-advanced-open` 已经是独立容器，好迁移）。

### 遗留专项（未做，已记账）

1. **入口体积结构性增长**：入口必须整包注册 i18n 字典（`t` 绑入口 ctx，locale 服务禁止同一
   NS 同一 locale 重复注册），每个新 key 让入口长 ~100 B；现有 600+ key、~15 KB 中文、
   无一冗余。根治方案：入口只注册 2 个 tab 标题 key + chunk 加载时填充延迟字典，
   可一次砍 ~15 KB（-23%）。见 `scripts/bundle-budget.mjs` 注释。
2. **多任务并发**（当前单 `generating`，图/视频互斥）——需要宿主任务队列设计。
3. **配音合成**——等 Threevideo TTS 接口联调。

## 2. 还缺的 8 件事（布局/优化靶点）

| # | 缺口 | 影响 | 落点 |
|---|---|---|---|
| 1 | 快速生成**不选模型** | 结果不对时无处可调，能力卡也白展示 | Hero 参数行加模型下拉（数据源 `modelsCatalog()`） |
| 2 | 参数是**裸 input** | 用户不知道能填什么，填错被上游拒 | 换 `iv-select`（时间轴已有现成组件） |
| 3 | 结果**不就地展示** | 一次创作上下滚 3~4 次 | 生成卡内联"本次结果"缩略图 + 查看/设为参考 |
| 4 | 快速路径**无风控** | 违禁词白跑一次（花钱/耗时） | 提交前 `checkPrompt`，block 禁用按钮 |
| 5 | 素材区**无搜索/排序** | 素材一多找不到 | 搜索框 + 按时间/类型排序 |
| 6 | 预览面板**不能送参考位** | 要回素材区选中再回 Hero | 预览加"设为参考/首帧/尾帧/参考视频" |
| 7 | 分镜 ↔ 一键成片**不通** | 剧本要复制两遍 | 分镜卡加"编排成流水线" |
| 8 | 失败**无下一步** | 用户卡住就放弃 | 错误条带动作：换模型 / 降时长 / 换参考图 |

## 3. 布局建议（Round 6 之后）

Round 6 把**样式令牌化 + 骨架统一**做完了，意味着现在改布局的"成本与风险都比之前低"（不用再和 8 条各自为政的容器规则打架）。
但**信息架构仍是"一列到底 + 底部 dock"**，核心问题没变：

1. 一列里塞了 6 块（Pipeline / Hero / 融合 / 工坊 / 分镜 / 能力卡），提示词与参数在滚动中段，顶部看不到。
2. **动作与结果分离**（按钮在中间，结果在最底部）。
3. **物料选择分散在 5 处**（Hero 参考图 / 融合 / 分镜 / 工坊 / 流水线），没有统一物料区。
4. dock 7 面板等权平铺，低频（诊断/健康）与高频（素材/任务）抢位置。

### 方案 A（推荐）三段式：左物料 / 中创作 / 右产物

```
┌ 顶栏 ──────────────────────────────────────────────────────────┐
├ 左 260px ─────┬ 中 1fr ──────────────────────┬ 右 320px ────────┤
│ 物料           │ 1 提示词（+风控提示条）        │ 本次结果        │
│ · 素材(搜索)   │ 2 参考（chips + 从物料区点选） │ 任务（进行中/历史）│
│ · 资源(分类)   │ 3 参数（模型/尺寸/比例/时长/续写）│ 导出(多比例)   │
│ · 提示词库     │ 4 生成（按钮+进度+下一步建议）  │ 诊断(折叠)      │
├───────────────┴──────────────────────────────┴─────────────────┤
│ 高级抽屉：融合生图 · 剧本分镜 · 一键成片 · 模型能力卡（按需展开）  │
└───────────────────────────────────────────────────────────────┘
```

- 动线：左选料 → 中写+调+生成 → 右立刻看结果；**一屏闭环，零上下滚动**。
- 融合/分镜/流水线从"常驻大卡"降级为**抽屉**，避免抢空间。
- 窄屏（<1180px）：右栏折叠为底部抽屉、左栏折叠为图标条。

### 方案 B 卡片流（最小改动，1 天量级）

保持单列，但 Hero 拆成 4 张可折叠卡（提示词/参考/参数/生成），生成卡内联结果缩略图。
优点：不动骨架；缺点：宽屏浪费、仍是纵向滚动。

### 方案 C 双栏 + 抽屉（折中）

主栏创作、右栏常驻（结果+任务），其余面板进抽屉；融合/分镜/工坊变成提示词框旁三个"魔法按钮"。

## 4. 优化优先级（建议）

| 优先级 | 事项 | 理由 |
|---|---|---|
| **P0** | 方案 A（或先用 B 过渡）+ 模型下拉联动能力卡 + 参数换 select | 决定"能不能用对"，观感权重最高 |
| **P0** | 结果就地展示 + 生成完自动定位 + 失败给下一步 | 去掉来回滚动与卡死放弃 |
| **P1** | 快速路径接风控（复用 `checkPrompt`） | 省一次白跑的钱 |
| **P1** | 统一物料区（素材+资源+提示词库，带搜索） | 消除 5 处分散选择器 |
| **P1** | 预览面板送参考位（参考/首帧/尾帧/参考视频） | 高频操作路径缩短一半 |
| **P2** | 分镜 → 一键成片直通；任务重试/失败展开/跳产物 | 打通链路与打磨 |
| **P3** | 多任务并发；配音合成（等 TTS 接口） | 依赖架构/外部 |

## 5. 结论

**能力面已经齐了**（B 批次 6 项 + 一键成片 + 融合 + 分镜 + 工坊 + 多比例 + 分类/重绘都在），
现在缺的是**信息架构**：把"一列到底"改成"左物料 / 中创作 / 右产物"，
再把模型选择、参数下拉、结果就地、风控、失败下一步这 5 个"决策点"补上——
快速创作就能从"功能齐全"变成"顺手好用"。
